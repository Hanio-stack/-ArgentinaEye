このサイトについて

ミレイ政権の改革、Vaca Muerta、RIGI、電力市場、海外資本と企業ニュースを追い、VIST / PAM / CEPU / TGS の投資テーマが前進しているかを毎朝確認するための公開ダッシュボードです。

この画面の見方（初心者向け）

1. まずスコアを見る
アルゼンチン全体と4銘柄の「事業テーマが順調か」を0〜100で表示します。株価が安い・買い時という意味ではありません。

2. 4社の役割を覚える
VIST＝掘る、PAM＝総合エネルギー、CEPU＝電気を作る、TGS＝ガスを運ぶ。下のカードで追い風と逆風を確認できます。

3. 7つの中核指標を見る
支持率、インフレ、外貨準備、財政、Vaca Muerta、RIGI、電力を確認。赤や悪化が増えた日だけ深掘りします。

4. 企業・大口資本ニュースを見る
4社のニュースに加え、Thiel / Hamm / Chevron / Mercuria / Eni / XRG などの資本移動を監視します。

日本語訳は機械翻訳です。翻訳時に外部サービスへ送るのは公開ニュースの見出しだけで、個人情報や保有情報は送信しません。

用語ミニ辞典
Vaca Muerta

アルゼンチンの巨大シェール油・ガス地域。VIST・PAM・TGSの成長テーマの中心。

RIGI

大型投資を呼び込むための優遇制度。承認額が増えても「もう稼働した」という意味ではない点に注意。

外貨準備

中央銀行が持つドルなどの外貨。通貨危機への「貯金」に近く、増える方が基本的に安心材料。

一次財政収支

国の収入−支出を、借金の利払いを除いて見た数字。黒字維持は財政改善のサイン。

bpd

barrels per day。1日に何バレルの原油を生産するか。k bpdなら「千バレル/日」。

信頼度

スコア計算に必要なデータがどれだけ揃っているか。高いほど「材料不足が少ない」という意味。
