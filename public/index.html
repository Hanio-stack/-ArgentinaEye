このサイトについて

ミレイ政権の改革、Vaca Muerta、RIGI、電力市場、海外資本と企業ニュースを追い、VIST / PAM / CEPU / TGS を題材に企業分析を勉強するためのダッシュボードです。売買を急ぐためではなく、「なぜ上がる・下がるのか」を自分で説明できるようになることを目的にしています。

この画面の見方（初心者向け）

1. まずスコアを見る
アルゼンチン全体と4銘柄の「事業テーマが順調か」を0〜100で表示します。株価が安い・買い時という意味ではありません。

2. 4社の役割を覚える
VIST＝掘る、PAM＝総合エネルギー、CEPU＝電気を作る、TGS＝ガスを運ぶ。下のカードで追い風と逆風を確認します。

3. 中核指標を見る
支持率、インフレ、外貨準備、財政、Vaca Muerta、RIGI、電力を確認。「会社のニュース」と「国全体の変化」をつなげます。

4. 次に株価の値段を見る
良い会社でも高すぎれば買いにくいので、PER / EV・EBITDA / FCF / 借金を別に考えます。下の「企業分析を学ぶ」で練習できます。

5. 最後に買う・買わないを考える
Bear / Base / Bull の3シナリオを作り、失敗した時の下落と成功した時の上昇を比べます。

企業分析を学ぶ

「良い会社」と「良い値段」を分けて考える

STEP 1

本業は強い？

EBITDA

利息・税金・減価償却などを引く前の、本業の稼ぐ力を見る目安。「この事業自体はどれくらい稼げる？」を見る。

STEP 2

値札は高い？

PER / EV・EBITDA

利益やEBITDAに対して、市場が何倍の値段を付けているか。同じ成長率なら、倍率が高いほど期待を先に織り込んでいる可能性があります。

STEP 3

現金は残る？

FCF

事業を動かし、必要な設備投資もした後に会社へ残る自由なお金。利益が出ていてもFCFが弱い会社は、大きな投資負担を抱えていることがあります。

STEP 4

借金は重い？

純有利子負債

ざっくり「借金 − 現金」。会社全体の価値が大きくても、借金が多いほど株主に残る価値は小さくなります。

STEP 5

未来を3つ作る

Bear / Base / Bull

弱気・標準・強気の3シナリオ。「当たる予言」を作るのではなく、どの前提が崩れると損するかを見える化します。

STEP 6

最後に株価へ

企業価値 → 株主価値

例：EBITDA × 評価倍率 ＝ 企業価値。そこから純負債を引き、株数で割ると1株の価値をざっくり考えられます。

超ざっくり式EBITDA × EV/EBITDA倍率 − 純負債 → 株主価値 → 株数で割る → 1株価値

ArgentinaEyeの次の段階では、この「バリュエーション（値段の評価）」を事業テーマ・スコアと分離して表示していきます。

買う前の5問

答えられなければ、まだ調べる余地あり

  1. この会社は何で儲けている？VISTなら原油、TGSなら輸送など、一文で言えるか。
  2. 何が起きれば利益が伸びる？生産量、油価、電力料金、輸送量など、主なドライバーを言えるか。
  3. 何が起きたら仮説が壊れる？政権交代、原油安、借金増、規制復活などを具体化できるか。
  4. その期待は株価にもう入っていない？PER / EV・EBITDA / FCF と過去の倍率を確認する。
  5. 半値になっても理由を説明して持てる？「下がったから怖い」ではなく、仮説が壊れたのか単なる値動きなのかを分ける。

中核指標

毎朝追う7つの重要指標

用語ミニ辞典
Vaca Muerta

アルゼンチンの巨大シェール油・ガス地域。VIST・PAM・TGSの成長テーマの中心。

RIGI

大型投資を呼び込むための優遇制度。承認額が増えても「もう稼働した」という意味ではない点に注意。

ADR

外国企業の株を米国市場で売買しやすくした「預託証券」。VIST / PAM / CEPU / TGS は米国市場でADRとして取引できます。

NISA成長投資枠

年間240万円まで使えるNISAの枠。米国個別株は主にこちら。つみたて投資枠とは別物です。

PER

株価が利益の何倍まで買われているか。低い＝必ず割安ではなく、成長期待やリスクとセットで見ます。

EBITDA

本業の稼ぐ力を見るための代表的な指標。設備の大きいエネルギー会社の比較でよく使われます。

EV / EBITDA

会社全体の値段（EV）がEBITDAの何倍か。企業同士の値段を比べる物差しのひとつ。

FCF

Free Cash Flow。設備投資などをした後に残る現金。将来の借金返済・配当・自社株買いなどの原資になります。

純有利子負債

ざっくり借金から現金を引いた額。増えすぎると、事業が伸びても株主価値を圧迫することがあります。

Bear / Base / Bull

弱気 / 標準 / 強気シナリオ。予言ではなく「どの前提ならどの株価になり得るか」を整理する方法。

外貨準備

中央銀行が持つドルなどの外貨。通貨危機への「貯金」に近く、増える方が基本的に安心材料。

一次財政収支

国の収入−支出を、借金の利払いを除いて見た数字。黒字維持は財政改善のサイン。

bpd

barrels per day。1日に何バレルの原油を生産するか。k bpdなら「千バレル/日」。

信頼度

スコア計算に必要なデータがどれだけ揃っているか。高いほど「材料不足が少ない」という意味。
