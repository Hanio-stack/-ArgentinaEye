このサイトについて

ミレイ政権の改革、Vaca Muerta、RIGI、電力市場、海外資本と企業ニュースを追い、VIST / PAM / CEPU / TGS を題材に企業分析を勉強するためのダッシュボードです。「良い会社か」と「今の値段で買いやすいか」を分けて考えます。

この画面の見方（初心者向け）

1. 事業テーマを見る
アルゼンチン全体と4銘柄の「事業環境が順調か」を0〜100で確認。高得点＝買い時ではありません。

2. 会社の役割を見る
VIST＝掘る、PAM＝総合エネルギー、CEPU＝電気を作る、TGS＝ガスを運ぶ。

3. 値段を見る
株価、PER、EV/EBITDA、FCF、借金を確認。「良い会社だけど高い」「安く見えるけど現金が弱い」を区別します。

4. Bear / Base / Bullを見る
弱気・標準・強気の前提を並べ、どの条件なら損益がどう変わるかを練習します。

5. 国の変化とニュースへ戻る
インフレ、外貨準備、財政、Vaca Muerta、RIGI、電力、企業ニュースを見て、シナリオの前提が崩れていないか確認します。

企業分析を学ぶ

上の数字が何を意味するか復習

STEP 1

本業は強い？

EBITDA

利息・税金・減価償却などを引く前の、本業の稼ぐ力を見る目安。

STEP 2

値札は高い？

PER / EV・EBITDA

利益やEBITDAに対して、市場が何倍の値段を付けているか。

STEP 3

現金は残る？

FCF

事業と必要な設備投資の後に残る自由なお金。利益とFCFが大きく違う会社もあります。

STEP 4

借金は重い？

純有利子負債 / Debt・EBITDA

借金が本業の稼ぐ力に対してどれくらい重いかを確認します。

STEP 5

未来を3つ作る

Bear / Base / Bull

予言ではなく、どの前提が崩れると損するのかを見える化する方法。

STEP 6

株価へ変換

企業価値 → 株主価値

EBITDA × 評価倍率から企業価値を作り、純負債を引いて1株価値へ変換します。

この画面のシナリオで使っている式EBITDA × EV/EBITDA倍率 − 純負債 → 株主価値 → ADR相当株数で割る → 1株価値

数値を当てることより、「何を変えると株価が変わるのか」を理解するための模型です。

買う前の5問

答えられなければ、まだ調べる余地あり

  1. この会社は何で儲けている？VISTなら原油、TGSなら輸送など、一文で言えるか。
  2. 何が起きれば利益が伸びる？生産量、油価、電力料金、輸送量など、主なドライバーを言えるか。
  3. 何が起きたら仮説が壊れる？政権交代、原油安、借金増、規制復活などを具体化できるか。
  4. その期待は株価にもう入っていない？PER / EV・EBITDA / FCF と52週の値動きを確認する。
  5. 半値になっても理由を説明して持てる？仮説が壊れたのか、単なる値動きなのかを分ける。

用語ミニ辞典
Vaca Muerta

アルゼンチンの巨大シェール油・ガス地域。VIST・PAM・TGSの成長テーマの中心。

RIGI

大型投資を呼び込む優遇制度。承認額が増えても「もう稼働した」という意味ではありません。

ADR

外国企業の株を米国市場で売買しやすくした預託証券。4社は米国市場でADRとして取引できます。

NISA成長投資枠

年間240万円まで使えるNISAの枠。米国個別株は主にこちら。

PER

株価が利益の何倍まで買われているか。低い＝必ず割安ではありません。

EBITDA

本業の稼ぐ力を見る代表的な指標。設備の大きいエネルギー会社の比較でよく使います。

EV / EBITDA

会社全体の値段（EV）がEBITDAの何倍か。

P / FCF

株主が持つ会社価値がFCFの何倍か。逆数はFCF利回りの目安になります。

Debt / EBITDA

借金がEBITDAの何年分くらいかを見る簡易指標。低いほど借金負担は軽い傾向。

Bear / Base / Bull

弱気 / 標準 / 強気シナリオ。予言ではなく前提の整理方法。

外貨準備

中央銀行が持つドルなどの外貨。通貨危機への「貯金」に近い数字。

一次財政収支

国の収入−支出を、借金の利払いを除いて見た数字。

bpd

barrels per day。k bpdなら「千バレル/日」。

信頼度
